# สรุปความรู้พื้นฐานเกี่ยวกับ Sensor

## 1. Sensor คืออะไร
Sensor (เซ็นเซอร์) คืออุปกรณ์ที่ใช้ตรวจจับสิ่งต่าง ๆ ในโลกจริง เช่น แสง ความร้อน ความดัน การเคลื่อนไหว หรือความชื้น แล้วแปลงข้อมูลเหล่านั้นให้เป็นสัญญาณที่อุปกรณ์อิเล็กทรอนิกส์เข้าใจได้

## 2. หลักการทำงานของ Sensor
Sensor จะทำงานโดยการรับข้อมูลจากสิ่งแวดล้อม จากนั้นจะเปลี่ยนข้อมูลนั้นเป็น:
- สัญญาณไฟฟ้า (เช่น แรงดัน หรือ กระแส)
- สัญญาณดิจิทัล (0 หรือ 1)
- ค่าเลขที่สามารถอ่านและประมวลผลได้

## 3. ประเภทของ Sensor ที่นิยมใช้
### 3.1 Sensor แสง
- ใช้ตรวจจับความเข้มของแสง
- ตัวอย่าง: LDR, photodiode

### 3.2 Sensor อุณหภูมิ
- ใช้ตรวจวัดอุณหภูมิ
- ตัวอย่าง: LM35, thermistor

### 3.3 Sensor ความดัน
- ใช้วัดแรงหรือความกด
- ตัวอย่าง: pressure sensor

### 3.4 Sensor ความชื้น
- ใช้วัดปริมาณความชื้นในอากาศ
- ตัวอย่าง: DHT11, DHT22

### 3.5 Sensor การเคลื่อนไหว
- ใช้ตรวจจับการเคลื่อนที่หรือการสั่นสะเทือน
- ตัวอย่าง: PIR sensor, accelerometer

## 4. Sensor มีหน้าที่อย่างไร
Sensor ช่วยให้ระบบอิเล็กทรอนิกส์สามารถรู้สภาพแวดล้อมจริงและตอบสนองอย่างอัตโนมัติ เช่น
- เปิดไฟอัตโนมัติเมื่อมืด
- ควบคุมความร้อนให้เหมาะสม
- ตรวจจับการเคลื่อนไหวในระบบรักษาความปลอดภัย

## 5. ความแตกต่างระหว่าง Analog และ Digital Sensor
### Analog Sensor
- ให้ค่าเป็นแบบต่อเนื่อง
- ตัวอย่างเช่น ค่าแรงดันที่เปลี่ยนตามอุณหภูมิ
- มักจะอ่านด้วย ADC

### Digital Sensor
- ให้ค่าเป็นแบบเลขฐานสอง (0/1)
- ใช้งานง่ายกว่าในระบบควบคุม
- มักจะส่งข้อมูลแบบตรงต่อระบบควบคุม

## 6. ตัวอย่างการใช้งาน Sensor ใน Arduino
Sensor สามารถเชื่อมต่อกับ Arduino แล้วอ่านค่าจากพอร์ต analog หรือ digital เช่น
- อ่านค่าอุณหภูมิจาก sensor
- อ่านค่าความชื้น
- ตรวจจับสัญญาณจากปุ่มหรือตัวตรวจจับ

## 7. ข้อควรระวังเมื่อใช้ Sensor
- ตรวจสอบแรงดันไฟฟ้าที่ใช้ให้เหมาะสม
- ใช้สายต่อและพอร์ตให้ถูกต้อง
- ปรับตั้งค่าตามเอกสารของตัว Sensor
- ควรทำการทดลองและสอบเทียบค่าที่ได้

## 8. สรุปสั้น
Sensor เป็นอุปกรณ์สำคัญที่ช่วยให้ระบบอิเล็กทรอนิกส์รับรู้โลกจริงได้ โดยการแปลงข้อมูลจากสิ่งแวดล้อมเป็นสัญญาณที่สามารถประมวลผลได้
