# LAB02 Blynk2LED

## ข้อมูลนักศึกษา
- รหัส: 68219090007
- ชื่อ: นายเตโช สงขำ
- แผนก: เทคนิคคอมพิวเตอร์

## วัตถุประสงค์
การใช้งาน LED 2 ตัว เพื่อให้ทำงานกระพริบสลับกัน โดยใช้ขา D12 และ D13 ของ Arduino UNO

## อุปกรณ์ที่ใช้
- Arduino UNO
- LED 2 ตัว
- ตัวต้านทาน 220Ω จำนวน 2 ตัว
- สายจัมเปอร์
- บอร์ดทดลอง (ถ้าจำเป็น)

## วิธีการต่อวงจร
- LED1 ต่อกับขา D12
- LED2 ต่อกับขา D13
- ขา Anode (+) ของ LED ต่อไปยังขา D12 / D13 ผ่านตัวต้านทาน 220Ω
- ขา Cathode (-) ของ LED ต่อกับ GND

### แบบร่างการต่อวงจร
```text
Arduino UNO                 LED1              LED2
-----------------------------------------------------------
D12  ──────[220Ω]─────| Anode (+)      |         
                    |               |         
GND ──────────────────| Cathode (-)    |         
D13  ──────[220Ω]─────|               | Anode (+)
GND ──────────────────|               | Cathode (-)
```

### วิธีการต่อแบบง่าย
1. ต่อขา Anode (+) ของ LED1 ผ่านตัวต้านทาน 220Ω ไปที่ D12
2. ต่อขา Cathode (-) ของ LED1 ไปที่ GND
3. ต่อขา Anode (+) ของ LED2 ผ่านตัวต้านทาน 220Ω ไปที่ D13
4. ต่อขา Cathode (-) ของ LED2 ไปที่ GND

> ควรต่อตัวต้านทานทุกครั้งเพื่อป้องกัน LED เสียหาย

## โค้ดตัวอย่าง
```cpp
#define LED1 12
#define LED2 13

void setup() {
  pinMode(LED1, OUTPUT);
  pinMode(LED2, OUTPUT);
}

void loop() {
  digitalWrite(LED1, HIGH);
  digitalWrite(LED2, LOW);
  delay(500);

  digitalWrite(LED1, LOW);
  digitalWrite(LED2, HIGH);
  delay(500);
}
```

## ผลลัพธ์ที่คาดหวัง
- LED1 จะสว่างและ LED2 จะดับ เป็นเวลา 0.5 วินาที
- จากนั้น LED1 จะดับและ LED2 จะสว่าง เป็นเวลา 0.5 วินาที
- ทำงานซ้ำอย่างต่อเนื่อง
