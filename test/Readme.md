## วัตถุประสงค์
เพื่อศึกษาข้อมูลพื้นฐานของเซ็นเซอร์ DHT11 และเข้าใจวิธีการใช้งานร่วมกับ Arduino UNO ในการวัดอุณหภูมิและความชื้น

## DHT11 คืออะไร
DHT11 คือเซ็นเซอร์แบบ Digital ที่ใช้วัดอุณหภูมิและความชื้นในอากาศ โดยสามารถส่งข้อมูลออกมาในรูปแบบดิจิทัลให้ไมโครคอนโทรลเลอร์ประมวลผลได้

## ภาพของ DHT11 (แบบเหมือนของจริง)
DHT11 มักเป็นตัวเซ็นเซอร์ที่มีลักษณะเป็นบอร์ดเล็ก ๆ มีช่องรับความชื้นและอุณหภูมิอยู่ด้านหน้า โดยทั่วไปจะมีขา 3 ขาหรือ 4 ขา และมักมีตัวถังสีส้ม หรือ สีฟ้า ขึ้นอยู่กับรุ่น

```text
         ┌──────────────┐
         │   DHT11       │
         │   (Sensor)    │
         │              │
         │  ┌────────┐   │
         │  │  holes │   │
         │  └────────┘   │
         └────┬─────┬────┘
              │     │
          VCC  DATA  GND
```

> รูปแบบขาอาจต่างกันเล็กน้อยตามรุ่น แต่หลักการใช้งานเดียวกัน

## คุณสมบัติของ DHT11
- วัดอุณหภูมิในช่วงประมาณ 0°C ถึง 50°C
- วัดความชื้นสัมพัทธ์ในช่วงประมาณ 20% ถึง 90%
- มีความแม่นยำไม่สูงมากนักเมื่อเทียบกับเซ็นเซอร์ระดับสูง
- ใช้งานง่ายและมีราคาถูก
- ข้อมูลส่งผ่านพินเดียวในรูปแบบดิจิทัล

## วิธีการต่อวงจร DHT11 กับ Arduino UNO
DHT11 มี 3 ขา หรือ 4 ขา ขึ้นอยู่กับรุ่น

### ขาแบบ 3 ขา
- VCC → 5V
- GND → GND
- DATA → ขา Digital ของ Arduino (เช่น D2)

### ขาแบบ 4 ขา
- VCC → 5V
- DATA → ขา Digital ของ Arduino
- NC → ไม่ใช้
- GND → GND

## ตัวอย่างการต่อวงจร
```text
Arduino UNO          DHT11
---------------------------
5V      ─────────── VCC
GND     ─────────── GND
D2      ─────────── DATA
```

## การทำงานของ DHT11
- เซ็นเซอร์จะอ่านค่าความชื้นและอุณหภูมิจากสภาพแวดล้อม
- หลังจากรับคำสั่งจาก Arduino จะส่งข้อมูลกลับมาในรูปแบบดิจิทัล
- Arduino จะประมวลผลข้อมูลและแสดงผลบน Serial Monitor

## ข้อควรระวังในการใช้งาน
- ต้องต่อ VCC และ GND ให้ถูกต้อง
- ควรใช้ตัวต้านทาน pull-up บนขา DATA ถ้าจำเป็น
- อย่าใช้สายไฟที่หลวมหรือชำรุด
- เวลาตอบสนองของเซ็นเซอร์อาจช้าเล็กน้อย

## ประโยชน์ของการใช้ DHT11
- เหมาะสำหรับงานเรียนรู้การอ่านข้อมูลจากเซ็นเซอร์
- ใช้ในระบบตรวจวัดอุณหภูมิและความชื้นเบื้องต้น
- ช่วยให้เข้าใจการทำงานของเซ็นเซอร์ดิจิทัลและการติดต่อกับไมโครคอนโทรลเลอร์

## สรุป
DHT11 เป็นเซ็นเซอร์ที่ง่ายต่อการเรียนรู้และเหมาะสำหรับการทดลองพื้นฐานเกี่ยวกับการวัดอุณหภูมิและความชื้น โดยใช้ Arduino UNO เป็นตัวควบคุมหลัก
