# Arduino UNO R3 และโครงสร้างของบอร์ด

## 1. Arduino UNO R3 คืออะไร
Arduino UNO R3 เป็นบอร์ดไมโครคอนโทรลเลอร์ที่ใช้ชิป ATmega328P มีความนิยมสูงมากในงานหุ่นยนต์และระบบอิเล็กทรอนิกส์ เพราะใช้งานง่ายและมีขาสำหรับต่ออุปกรณ์ต่าง ๆ ได้หลากหลาย

## 2. ส่วนประกอบหลักของบอร์ด
- **ไมโครคอนโทรลเลอร์ (ATmega328P)**: ทำหน้าที่ประมวลผลคำสั่ง
- **USB Port**: ใช้สำหรับอัปโหลดโค้ดและเชื่อมต่อกับคอมพิวเตอร์
- **Power Jack**: สำหรับจ่ายไฟจากแหล่งภายนอก
- **Reset Button**: ใช้เพื่อเริ่มโปรแกรมใหม่
- **Voltage Regulator**: ควบคุมแรงดันไฟให้เหมาะสม
- **Crystal Oscillator**: ให้สัญญาณนาฬิกาเพื่อควบคุมการทำงาน
- **LED Built-in**: LED ที่ต่อกับพิน 13 ใช้สำหรับทดสอบเบื้องต้น

## 3. ขาใช้งานของ Arduino UNO R3
บอร์ด UNO มีขาแบบ **Digital** และ **Analog** ที่สามารถต่อกับเซ็นเซอร์และอุปกรณ์ต่าง ๆ ได้

### 3.1 ขา Digital
- พิน `0` - `13` เป็นขา Digital
- ใช้สำหรับอ่านสัญญาณแบบ ON/OFF หรือส่งสัญญาณ HIGH/LOW
- ขา `0` และ `1` ใช้สำหรับ Serial Communication
- ขา `13` มี LED ในตัวบอร์ด

### 3.2 ขา Analog
- พิน `A0` - `A5` เป็นขา Analog Input
- ใช้สำหรับอ่านค่าแรงดันที่มีค่าเป็นแบบต่อเนื่อง
- เหมาะกับเซ็นเซอร์ที่ให้ค่า analog เช่น LM35, LDR

### 3.3 ขา Power
- **5V**: จ่ายแรงดัน 5 โวลต์ให้กับอุปกรณ์ภายนอก
- **3.3V**: จ่ายแรงดัน 3.3 โวลต์
- **GND**: ขา接地
- **VIN**: ใช้สำหรับจ่ายไฟจากภายนอกเข้าบอร์ด

## 4. การใช้งานขาในงานจริง
- ใช้ `digitalWrite()` เพื่อส่งค่า HIGH หรือ LOW ไปยังอุปกรณ์ เช่น LED, Relay
- ใช้ `digitalRead()` เพื่ออ่านสถานะของปุ่มหรือสัญญาณดิจิทัล
- ใช้ `analogRead()` เพื่ออ่านค่าจากเซ็นเซอร์แบบ analog
- ใช้ `pinMode()` เพื่อกำหนดขาเป็น INPUT หรือ OUTPUT

## 5. ตัวอย่างการต่ออุปกรณ์เบื้องต้น
### ต่อ LED เข้ากับขา Digital
- ขา `13` → LED
- GND → ขาอีกข้างของ LED

### ต่อ Sensor Analog
- ขา `A0` → ขา Analog Output ของ Sensor
- 5V → จ่ายไฟให้ Sensor
- GND → ขา GND ของ Sensor

## 6. ข้อควรระวังในการใช้งาน
- อย่าจ่ายแรงดันเกินค่าที่อุปกรณ์รองรับ
- ตรวจสอบการต่อ GND ให้ถูกต้อง
- หลีกเลี่ยงการต่อขา Output กับ Input โดยไม่ทราบโหมดการทำงาน
- ใช้สายต่อให้แน่นและไม่หลวม

## 7. สรุป
Arduino UNO R3 มีโครงสร้างที่ง่ายต่อการเรียนรู้ และมีขาใช้งานหลากหลาย เหมาะสำหรับการเริ่มต้นเรียนรู้เซ็นเซอร์และระบบควบคุมอัตโนมัติ
